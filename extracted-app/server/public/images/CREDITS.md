# Word picture credits

Most pictures in this folder are emoji graphics from **Twemoji**
(https://github.com/jdecked/twemoji, version 15.1.0),
copyright Twitter, Inc. and other contributors, licensed under
**CC-BY 4.0** (https://creativecommons.org/licenses/by/4.0/).
The app credits them on its home screen, as the licence requires.

The pictures copied from `assets/custom-images/` (Indian food, festivals, places and other words with
no emoji) were drawn for this project in the same style.

Do not edit files here by hand: run `npm run images` (see `scripts/fetch-images.ts`).
